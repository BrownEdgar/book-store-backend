# BACK with FSD Arc

## before start

- add env

```bash
PORT=3000
MONGO_URI="your mongoDB URL here"
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/BrownEdgar/book-store-backend.git
```

📦 Install Dependencies and run

```bash
npm install
npm run dev
```

| Command         | Description                       |
